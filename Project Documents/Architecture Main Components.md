| Component                                          | What it is supposed to do                                                                                                                                                                                                                                        |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Start / Trigger Component**                      | Entry point into the system. Starts a run either from a scheduled monitoring job or from a user prompt/request.                                                                                                                                                  |
| **Scheduler**                                      | Triggers tariff-monitoring runs periodically or at configured intervals. Can also simulate scheduled monitoring for the assignment.                                                                                                                              |
| **ADK Agent / Orchestrator**                       | Coordinates the end-to-end workflow, decides which tools to call, manages state/session information, applies stopping conditions, and separates LLM-driven decisions from deterministic logic.                                                                   |
| **User Intent + Product Resolution**               | Understands what the user is asking for and identifies the intended banking product, including Armenian/English synonyms, fuzzy names, and imprecise product descriptions.                                                                                       |
| **Official Source Discovery**                      | Searches only within the approved bank domain/allowlist to find relevant official product pages and documents such as information summaries or tariff PDFs.                                                                                                      |
| **Relevant Document Recognition / Source Ranking** | Evaluates multiple candidate pages/documents and selects the most authoritative and relevant source for the requested product. Can also detect ambiguity or conflicting official sources.                                                                        |
| **Website Scraper / HTML Retriever**               | Retrieves and extracts content from official bank webpages while respecting domain restrictions, timeouts, and retrieval limits.                                                                                                                                 |
| **PDF Downloader**                                 | Downloads official PDF documents with security controls such as domain validation, redirects checking, file-size limits, MIME-type validation, and network timeouts.                                                                                             |
| **PDF Parser / Document Content Extractor**        | Extracts text, tables, page structure, and relevant information from digital PDFs without OCR when possible.                                                                                                                                                     |
| **OCR Fallback**                                   | Handles scanned or image-based PDFs when normal PDF extraction fails or produces insufficient content. Should also provide an OCR quality/confidence signal where possible.                                                                                      |
| **Document Quality Check**                         | Determines whether extracted document content is usable and whether OCR, retry, or human review is required.                                                                                                                                                     |
| **Document Cleaning & Structuring**                | Removes repeated headers/footers, page numbers, duplicate content, broken lines, and formatting noise; preserves headings, sections, tables, Armenian text, and page boundaries.                                                                                 |
| **Chunking & Metadata Builder**                    | Splits cleaned content into meaningful chunks and attaches metadata such as bank, product, document name, source URL, page, section, language, and retrieval time.                                                                                               |
| **RAG Index / Knowledge Store**                    | Stores/indexes document chunks so they can be retrieved later using vector, lexical, or hybrid search.                                                                                                                                                           |
| **RAG Retrieval Component**                        | Retrieves the most relevant evidence-bearing chunks for the requested tariff information and filters out irrelevant results.                                                                                                                                     |
| **Structured Tariff Extraction**                   | Uses Gemini/structured output to extract tariff fields such as currency, term, amount, nominal rate, effective rate, fees, collateral, and salary-customer privileges. Missing values must be explicitly represented as `NOT_FOUND`.                             |
| **Normalization Component**                        | Converts equivalent values into canonical forms, e.g. `10 000 000 AMD` and `10,000,000 AMD`, normalizes percentages, currencies, durations, ranges, and numerical formats.                                                                                       |
| **Deterministic Validation Component**             | Applies non-LLM validation rules for schema correctness, required fields, value/range formats, domain validation, currency representation, duration formats, file constraints, and missing values.                                                               |
| **Evidence / Provenance Component**                | Associates each important extracted value with its source URL, document, page, section, and supporting evidence so the result can be independently verified.                                                                                                     |
| **Snapshot Storage / Repository**                  | Persists normalized tariff results from each monitoring run and retrieves previous snapshots for comparison. Stores timestamps and source/document metadata.                                                                                                     |
| **Change Detection Component**                     | Compares the current normalized snapshot against the previous one and reports only meaningful tariff changes while ignoring formatting-only differences.                                                                                                         |
| **HITL / Human Review Component**                  | Routes ambiguous or risky situations to a reviewer, such as conflicting PDFs, low OCR quality, missing critical values, multiple plausible documents, or unusually large tariff changes.                                                                         |
| **Error Handling & Retry Component**               | Handles failures such as HTTP timeouts, 404s, parsing errors, OCR failures, Gemini/API errors, malformed structured output, irrelevant RAG retrieval, product-not-found, and missing previous snapshots. Applies bounded retries/backoff only where appropriate. |
| **Security / Guardrails**                          | Enforces domain allowlists, least-privilege tools, input/output validation, safe download limits, secret management, and prevents unrestricted LLM access to filesystem, databases, or arbitrary network operations.                                             |
| **Logging / Observability**                        | Produces structured logs/traces for each run, including request, agent/tool activity, retrieval, RAG results, extraction, validation, HITL outcome, failures, duration, and other useful metrics.                                                                |
| **Log Sanitizer**                                  | Removes or masks API keys, secrets, sensitive headers, unnecessary document content, and other values that should not appear in logs.                                                                                                                            |
| **Result / Report Builder**                        | Produces the business-facing final output showing extracted tariff values, official sources, evidence, validation status, uncertainty, and detected changes.                                                                                                     |
| **Configuration Component**                        | Centralizes settings such as allowed domains, model configuration, file-size limits, timeout/retry settings, paths, environment variables, and secret references.                                                                                                |
| **Automated Test Suite**                           | Tests deterministic logic such as normalization, validation, tariff comparison, URL/domain validation, parsing, and error handling.                                                                                                                              |
| **Evaluation Harness**                             | Runs a small representative evaluation dataset against the agent/RAG pipeline and measures expected product resolution, retrieval quality, evidence correctness, extraction accuracy, and completeness.                                                          |
